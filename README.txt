EMBER & OLIVE — RESTAURANT LANDING PAGE
======================================

HOW TO RUN
1. Extract the ZIP file.
2. Open the ember_and_olive_restaurant folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

PROJECT STRUCTURE
- index.html       Main landing page
- css/style.css    Layout, responsive styles, animations
- js/script.js     Mobile menu, scroll reveal, dynamic footer year
- images/          Image source and usage notes

FEATURES
- Premium restaurant branding and custom text logo
- Responsive desktop, tablet and mobile layout
- Hero, story, values, featured menu, experience, gallery, reservation and footer sections
- Mobile navigation
- Scroll reveal animations and subtle hero zoom
- Google Fonts (Playfair Display + DM Sans)
- Font Awesome icons
- SEO description and mobile theme color

IMPORTANT CUSTOMIZATION
- Restaurant name: search for “Ember & Olive” in index.html.
- Address, phone and email: edit the footer and reservation link in index.html.
- Menu names and prices: edit the menu-card items in index.html.
- Images: see images/README.txt for the real Unsplash photo sources and local-image instructions.
- Reservation phone is a demo placeholder (+880 1700-000000). Replace it with the restaurant's real number before publishing.
- Social links are placeholders (#); add the restaurant's real profile URLs.

The Google Fonts, Font Awesome and Unsplash photos require an internet connection.
