IMAGE ASSETS
============
The website currently loads its real, non-AI food and restaurant photographs directly from Unsplash so the demo works without storing large duplicate image binaries in this starter package.

Photo sources used in index.html and css/style.css:
- https://images.unsplash.com/photo-1517248135467-4c7edcad34c4 (restaurant interior)
- https://images.unsplash.com/photo-1504674900247-0877df9cc836 (food platter)
- https://images.unsplash.com/photo-1414235077428-338989a2e8c0 (fine dining)
- https://images.unsplash.com/photo-1565299624946-b28f40a0ae38 (pizza)
- https://images.unsplash.com/photo-1509440159596-0249088772ff (artisan bread)

These are photographic image URLs, not AI-generated images. Internet access is required for them to load. To make the site fully offline, download the photos from the source URLs, save them in this folder, and replace the remote URLs in index.html and css/style.css with local paths such as images/restaurant-interior.jpg.

Unsplash license information: https://unsplash.com/license
